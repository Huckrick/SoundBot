## 简体中文

导入自己的音效库，按文件名、标签和描述搜索。打开波形试听、框选和调整效果，再把选区拖到 DAW，或在中间件工作台混音并交付。

![SoundBot 深色中文音效库](docs/images/library-zh-dark.png)

- **音效库**支持来源目录、增量导入、收藏、分组和本地搜索。
- **波形编辑**支持选区、增益、淡入淡出、循环试听和 WAV 拖出。
- **中间件工作台**支持多轨编辑、试听、效果器和渲染。各宿主的交付流程见[操作指南](docs/middleware.md)。
- **素材详情**显示音频规格、嵌入封面和源文件标签。核心浏览、编辑和试听可离线使用。

## English

Import your sound library and search by filename, tags, or description. Audition a waveform, select a region, and apply effects before dragging the selection into a DAW or mixing it in the middleware workspace.

![SoundBot light English middleware workspace](docs/images/workspace-en-light.png)

- **Sound library** with source folders, incremental imports, favorites, groups, and local search.
- **Waveform editing** with range selection, gain, fades, loop playback, and WAV drag-out.
- **Middleware workspace** with multitrack editing, audition, effects, and rendering. See the [host workflow guide](docs/middleware.md).
- **Asset details** with audio properties, embedded artwork, and original file tags. Core browsing, editing, and playback work offline.
