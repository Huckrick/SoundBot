SoundBot audio runtime third-party notices
==========================================

PyAV
-----
Source (18.0.0): https://github.com/PyAV-Org/PyAV/tree/v18.0.0
License: BSD-3-Clause

The complete PyAV license shipped by the installed wheel is collected from
the ``av`` distribution metadata into this frozen bundle.  The source code
for the exact PyAV release is available from the project URL above.

FFmpeg libraries bundled by the PyAV wheel
------------------------------------------
Source (8.1.2): https://github.com/FFmpeg/FFmpeg/tree/n8.1.2
Wheel build recipes: https://github.com/PyAV-Org/pyav-ffmpeg/tree/8.1.2-1
License information: https://ffmpeg.org/legal.html

PyAV binary wheels include FFmpeg shared libraries.  FFmpeg is generally
available under LGPL-2.1-or-later, but optional build flags can change the
applicable terms.  SoundBot release CI verifies and publishes only the
libraries supplied by the pinned PyAV wheel. The macOS arm64 build reports
LGPL version 3 or later. The recipe also builds auxiliary codec libraries;
their notices and corresponding source are assessed separately per platform.

This notice is informational and does not replace the license texts shipped
with PyAV or FFmpeg.

Mutagen and Pillow
-----------------
Mutagen reads embedded audio tags and artwork (GPL-2.0-or-later).
Project and source: https://github.com/quodlibet/mutagen

Pillow decodes embedded artwork and prepares bounded display images (MIT-CMU).
Project and source: https://github.com/python-pillow/Pillow

The frozen bundle includes the distribution metadata and license notices
for the pinned versions of both packages.

Pedalboard
----------
Source (0.9.22): https://github.com/spotify/pedalboard/tree/v0.9.22
The frozen wheel includes its GPLv3 license and the upstream NOTICE describing
the components built into the host. Plug-ins selected by the user are governed
by their own terms.

libebur128 filter coefficient calculation
----------------------------------------
The live loudness meter adapts the sample-rate coefficient calculation from
libebur128. Source: https://github.com/jiixyj/libebur128
